The Battery's Last Text to Its Charger: a program that writes one text to `/output/entry.txt` — one original one-line last text from a phone battery to the charger it waited for all day, under 200 characters.

> I've been on 1% since lunch, watching you scroll. When I die, your alarms die with me. Good luck waking up.

## Run it

```sh
python3 main.py
```
